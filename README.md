# Todo App

A responsive task management application built with React to practice state management, CRUD functionality, and reusable component development.

## 🚀 Demo

https://react-todo-app-1.netlify.app/


## ✨ Features

* Add new tasks
* Edit existing tasks
* Delete tasks
* Mark tasks as completed
* Manage application state with Context API
* State management with useReducer
* Responsive user interface
* Reusable React components

## 🛠️ Tech Stack

* React
* JavaScript
* Context API
* useReducer
* Tailwind CSS
* Vite
* Git & GitHub

## 📂 Main Functionality

* Create tasks
* Read and display tasks
* Update existing tasks
* Delete tasks
* Mark tasks as completed
* Manage Todo state with Context API and useReducer

## 🚀 Project Overview

Todo App is a task management application developed to strengthen my understanding of React state management and CRUD operations.

The project uses **Context API** and **useReducer** to manage application state and handle Todo-related actions in a structured way.

## 💻 Getting Started

Clone the repository:

```bash
git clone https://github.com/mubinaxmdva/react-todo-app
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
